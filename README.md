# 高德 MCP × DeepSeek 地图助手

这个项目用地图问题展示 Agent 调用 MCP 的完整链路，并支持在网页中继续追问：

```text
用户问题 → DeepSeek 选择工具 → Python 程序调用高德 MCP → 工具结果交回 DeepSeek → 最终回答
```

它不是让大模型“自动拥有地图知识”。模型只负责理解问题和选择工具；地点、路线和天气等外部事实来自高德 MCP 的实际返回。

## 准备

1. 将 `.env.example` 复制为 `.env`。
2. 在 `.env` 中填写新的高德 Key 与 DeepSeek API Key。
3. 安装依赖：

   ```powershell
   python -m pip install -r requirements.txt
   ```

4. 运行：

   ```powershell
   python amap_mcp_demo.py
   ```

5. 输入一个地图问题，例如：`北京大学东门附近有哪些咖啡店？`

## 网页版

网页版使用同一个 Agent。先完成上面的密钥配置和依赖安装，然后在项目目录运行：

```powershell
python web_app.py
```

在浏览器打开 `http://127.0.0.1:8000`，输入问题并点击“发送”。可以继续追问上一轮内容，也可以点击“清空对话”重新开始。答案下方的“查看调用过程”会展示模型决策、MCP 工具调用和结果摘要。这个服务器只监听本机；按 `Ctrl+C` 停止。

请保持运行 `python web_app.py` 的终端窗口打开，也不要双击 `index.html` 文件直接打开页面。浏览器地址栏应以 `http://127.0.0.1:8000` 开头；如果以 `file:///` 开头，浏览器无法请求后端接口，会显示连接失败。

如果页面返回“地图或模型服务暂时不可用”，说明请求已经到达后端。此时查看运行 `python web_app.py` 的终端：那里会显示脱敏后的真实错误。修改 Python 文件后，先按 `Ctrl+C` 停止旧服务器，再重新运行 `python web_app.py`。

### 前端与后端如何交互

这个例子只有两个入口文件：[index.html](index.html) 是浏览器界面，[web_app.py](web_app.py) 是 Python 后端。一次提问的步骤是：

1. 浏览器中的 JavaScript 读取输入框，执行 `fetch("/api/chat", ...)`，发送一个 POST 请求。
2. 请求正文是 JSON，例如 `{"question":"北京大学东门附近有哪些咖啡店？"}`。
3. Python 后端读取 `question`，从本机内存取出此浏览器会话的最近问答，再调用 [amap_mcp_demo.py](amap_mcp_demo.py) 中的 `ask_agent()`。该函数把上下文交给 DeepSeek，并连接高德 MCP 选择和调用工具。
4. 后端把结果作为 JSON 返回，例如 `{"answer":"...", "events":[{"stage":"工具调用", "message":"..."}]}`。
5. JavaScript 从响应中取出 `answer` 和 `events`，添加到页面。页面只是显示数据，不直接接触密钥。

浏览器只发送本轮问题；后端按浏览器 Cookie 区分对话，在内存中最多保留最近 20 轮问答，并把最近 6 轮提供给模型理解追问。刷新页面会从后端恢复消息；点击“清空对话”会删除当前会话的上下文；重启后端会清空全部内存对话。模型每轮仍会重新调用地图工具核实需要当前事实的问题。

## 批量演示

可运行 5 条固定的模拟用户输入，依次覆盖地点搜索、路线规划、天气、信息不足和非地图问题：

```powershell
python run_demo_tests.py
```

此命令会实际调用高德 MCP 与 DeepSeek API，并消耗相应的服务额度。

## 输出说明

脚本会依次打印：

1. 高德 MCP 返回的可用工具；
2. DeepSeek 选择的工具及其参数；
3. MCP 工具结果摘要；
4. DeepSeek 基于工具结果生成的最终回答。

若地点信息不足、服务未返回结果或调用失败，模型会收到对应的工具错误并给出说明，而不是把猜测伪装成地图事实。

## 安全

- `.env` 已被 `.gitignore` 排除，绝不应提交或发送其中的 Key。
- 已出现在聊天记录中的高德 Key 应立即在高德开放平台轮换；本项目没有写入该 Key。
- 脚本不会打印 MCP 连接 URL，因此不会显示高德 Key。

## 网页重启与故障排查

修改了 `web_app.py` 或遇到网页异常时，按下面的顺序重新启动：

1. 回到正在运行网页的 PowerShell 窗口，按 `Ctrl+C`，看到“网页已停止”。
2. 在项目目录重新运行：

   ```powershell
   python web_app.py
   ```

3. 保持这个 PowerShell 窗口打开，在浏览器访问或刷新 `http://127.0.0.1:8000`。
4. 重新输入问题并点击“发送”。刷新前页面上的红色错误是旧请求的结果，不能用它判断新服务器是否正常。

页面显示“本机后端已连接”表示浏览器可以访问 Python 后端；这还不代表高德 MCP 和 DeepSeek 已完成调用。如果新问题返回“地图或模型服务暂时不可用”，请查看运行 `python web_app.py` 的 PowerShell 窗口，那里会显示已脱敏的具体错误。

如果启动时提示 `127.0.0.1:8000 已被占用`，说明已有服务器进程正在使用该端口。先停止旧服务器，再重新运行；不要同时打开多个 `python web_app.py` 进程。
